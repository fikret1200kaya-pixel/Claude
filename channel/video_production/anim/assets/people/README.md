Drop licensed photos here and the video engine will show them automatically (framed, with the credit line under the photo).
Without a photo the scene falls back to a clean name card (no icon).

## Where to get them (free, legal)
- Wikimedia Commons (commons.wikimedia.org): search the person's name, open the file page, check the **License** box.
- Use only: **Public domain**, **CC0**, **CC BY**, **CC BY-SA**. Do NOT use photos from Getty, AP, Reuters, magazines or Google Images.
- Portrait shape about 4:5, at least 600 px tall. Save as `.jpg` with the file names above.

## Credits (required for CC BY / CC BY-SA)
1. Put the credit in `credits.js`, e.g. `icahn: 'Photo: Author Name / Wikimedia Commons / CC BY-SA 2.0'`.
2. Also paste the same credit line in the YouTube video description.

## Important
- Photos of real people are fine as documentary illustration. Do not use AI-generated realistic faces of real people.
- If no free photo exists for someone, leave the file out. The name card is used instead.
